# Картинки персонажей

Сюда попадают изображения, которые показывает игра. Файлы складывает скрипт
[`backend/seed_narutodle.py`](../../../../backend/seed_narutodle.py):

```powershell
py backend/seed_narutodle.py --dsn "postgresql://greenhouse@localhost:5432/greenhouse" `
    --images C:\photos
```

Скрипт сшивает имя файла с именем персонажа без учёта регистра и расширения
(`наруто узумаки.jpg` → «Наруто Узумаки»), копирует файл сюда и прописывает путь
в колонку `image` таблицы `narutodle_characters`. Если имена не совпадают,
соответствия задаются файлом `--map` (JSON вида `{"файл.jpg": "Имя персонажа"}`).

Если у персонажа картинки нет, страница рисует аватар сама: инициалы на цвете
деревни из `narutodle_data.VILLAGE_COLORS`.

**Важно про авторские права.** Используйте только те изображения, на которые
у вас есть право: свои рисунки, работы с разрешением автора или материалы
со свободной лицензией. Официальные кадры и иллюстрации «Наруто» защищены
авторским правом, и выкладывать их на сайте нельзя.

Пустая папка — нормальное состояние: без файлов игра работает на аватарах.

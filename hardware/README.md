# Аппаратная часть (Arduino Nano) — теплица на 12 участков

Прошивка: [`arduino/greenhouse_12zone/greenhouse_12zone.ino`](arduino/greenhouse_12zone/greenhouse_12zone.ino)

## Что понадобится

| Компонент | Кол-во | Назначение |
|---|---|---|
| Arduino Nano (ATmega328P) | 1 | контроллер, 14 цифровых и 8 аналоговых входов |
| CD74HC4067 (16-канальный аналоговый мультиплексор) | 1 | опрос 12 датчиков влажности + LDR |
| Датчики влажности почвы (ёмкостные) | 12 | по одному на участок |
| DHT22 | 1 | температура воздуха (влажность — резерв протокола) |
| HC-SR04 | 1 | уровень воды в баке |
| 74HC595 | 2 | 16 выходов управления (насосы/вентилятор/лампа) |
| Модуль реле 16 каналов (или MOSFET) | 1 | коммутация насосов и лампы |
| Насосы (мини-помпы) | 12 | полив каждого участка |
| Вентилятор 12 В | 1 | проветривание |
| Фитолампа LED 12 В | 1 | досветка (вкл./выкл. через MOSFET-модуль) |

## Схема соединений

```
                    Arduino Nano
   +--------------------------------------------------+
   |  A0  <-------- SIG   CD74HC4067                  |
   |  D2..D5 ------> S0..S3 мультиплексора            |
   |  D6  <-------- DATA  DHT22                       |
   |  D7  --------> TRIG  HC-SR04                     |
   |  D8  <-------- ECHO  HC-SR04                     |
   |  D9  --------> DS   74HC595 #1 (каскад -> #2)    |
   |  D10 --------> SHCP (clock)                      |
   |  D11 --------> STCP (latch)                      |
   |  D12, D13, A1..A7 — свободны                     |
   +--------------------------------------------------+

   CD74HC4067:  C0..C11 -> датчики влажности участков 1..12
                C12     -> фоторезистор (освещённость)

   74HC595:  Q0..Q11 -> реле насосов участков 1..12
             Q12     -> реле вентилятора
             Q13     -> MOSFET-модуль фитолампы
```

Питание: насосы и лампа — от отдельного блока 12 В; модуль реле и датчики —
от отдельного блока 5 В (до 2 А), не от вывода `5V` платы. Обязательно
объединить земли (GND) всех блоков.

Память: у ATmega328P всего 2 КБ SRAM, поэтому кадр телеметрии печатается в
Serial потоком — без JSON-документа на 12 участков.

## Библиотеки

* **ArduinoJson** (v6) — разбор команд.
* **DHT sensor library** (Adafruit) + **Adafruit Unified Sensor**.

## Сборка

В Arduino IDE: плата **Arduino Nano**, процессор **ATmega328P**, порт COM3.

Через PlatformIO (конфигурация лежит рядом со скетчем):

```powershell
pio run -d hardware/arduino/greenhouse_12zone
pio run -d hardware/arduino/greenhouse_12zone -t upload
```

Проверено: Flash — 12 984 из 30 720 байт (42,3 %), RAM — 675 из 2 048 байт (33,0 %).

## Протокол обмена

Скорость порта — **115200 бод**, формат — построчный JSON (`\n` в конце).

Плата → сервер:

```json
{"type":"hello","fw":"1.0","zones":12}
{"type":"readings","tank":78.5,"data":[
  {"zone":1,"temperature":24.5,"moisture":48,"light":12400}
]}
{"type":"ack","zone":3,"device":"watering","on":true}
```

Сервер → плата:

```json
{"cmd":"set","zone":3,"device":"watering","on":true,"seconds":10}
```

Идентификаторы исполнителей: `watering` (насос участка), `ventilation` (вентилятор),
`lighting` (фитолампа).

## Запуск с реальной платой

```powershell
# Windows, порт COM3
python backend/server.py --serial COM3 --port 8000
```

Если порт не указан — сервер поднимает **эмулятор** и работает без железа.

## Калибровка датчиков влажности

В прошивке заданы константы `SOIL_DRY` и `SOIL_WET` (значения АЦП в сухой и
насыщенной почве). Для калибровки:

1. Прошить, открыть монитор порта (115200), погрузить датчик в воздух → записать значение;
2. Погрузить в воду (или насыпную влажную почву) → записать значение;
3. Подставить оба значения в константы и перепрошить.
